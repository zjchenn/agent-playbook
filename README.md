# Agent Playbook

我的 agent 工作台：面向各类 coding agent 的技能与配置。
仓库内的文件是唯一源，以软链装到各 agent，随仓库更新。

## 目录

| 目录 | 内容 |
|------|------|
| [`opencode/`](opencode/README.md) | opencode 的配置 |
| [`pi/`](pi/README.md) | pi 的配置与扩展 |
| [`skills/`](skills/README.md) | agent 技能 |

## 安装

把下面这句话发给任意 coding agent，它会先列出安装计划，等你确认后再动手：

```text
读 https://github.com/zjchenn/agent-playbook/blob/master/INSTALL.md ，按它帮我配置。
```
